Quiero mejorar el prototipo existente de mi aplicación móvil “CaserIA”. NO crees una aplicación diferente ni cambies el concepto principal. Mantén el estilo visual, identidad, colores, tipografía, estructura y pantallas existentes siempre que sea posible.

CaserIA ayuda a las personas a hacer rendir mejor su presupuesto de alimentos. El flujo principal del comprador es:

Presupuesto → selección de productos → cantidades → generación de canasta → comparación de precios entre establecimientos → elección del lugar de compra.

También existe un flujo para vendedores:

Registro del establecimiento → productos → precios → actualización de precios → visibilidad ante compradores.

El prototipo ya fue testeado con compradores y vendedores. Quiero realizar una tercera versión incorporando mejoras obtenidas directamente de la retroalimentación de los usuarios.

IMPORTANTE:
- No elimines las funciones que ya existen.
- No cambies el concepto de CaserIA.
- No conviertas la aplicación en un e-commerce completo.
- Mantén diferenciados los perfiles de Comprador y Vendedor.
- Prioriza facilidad de uso, claridad, navegación simple y diseño intuitivo.
- Mantén las funciones Premium diferenciadas de las funciones gratuitas.
- No hagas que funciones esenciales como comparar precios o contactar/reservar dependan de Premium.

IMPLEMENTA LAS SIGUIENTES 8 MEJORAS:

1. MEJORAR EL INGRESO DEL PRESUPUESTO
Rediseña la pantalla donde el comprador registra cuánto dinero tiene disponible.
- Mostrar claramente: “¿Cuál es tu presupuesto para esta compra?”
- Campo grande para ingresar el monto en soles: “S/ ___”.
- Mostrar el presupuesto disponible durante el proceso.
- Agregar un botón principal visible: “Crear mi canasta” o “Continuar”.
- Evitar elementos que puedan confundir al usuario.

2. MEJORAR LA NAVEGACIÓN
Haz que las funciones principales sean fáciles de encontrar.
Utiliza una navegación sencilla con accesos visibles como:
- Inicio
- Mi canasta
- Comparar
- Perfil

Mantén una jerarquía visual clara y botones principales fáciles de reconocer.

3. INCORPORAR UNIDADES DE MEDIDA
Cada producto debe mostrar claramente su unidad y precio.

Ejemplos:
- Arroz – S/ 4.50/kg
- Leche – S/ 5.20/L
- Huevos – S/ 0.70/unidad
- Fideos – S/ 3.50/paquete

Cuando el usuario modifique cantidades, debe entender claramente si está seleccionando kg, litros, unidades o paquetes.

4. MEJORAR LA COMPARACIÓN ENTRE ESTABLECIMIENTOS
Rediseña la pantalla de comparación para que el comprador pueda identificar rápidamente dónde le conviene comprar.

Cada establecimiento debe mostrar:
- Nombre del establecimiento
- Tipo: Mercado / Supermercado
- Costo total de la canasta
- Ahorro estimado
- Distancia aproximada
- Disponibilidad de los productos
- Fecha o estado de actualización de los precios

Destaca visualmente la mejor alternativa con un mensaje como:
“Mejor opción”
o
“Ahorras S/ 12.50”.

Permite que el usuario pueda considerar tres criterios:
- Ahorrar al máximo
- Comprar todo en un solo lugar
- Comprar cerca

5. MOSTRAR LA ACTUALIZACIÓN DE LOS PRECIOS
Incorpora indicadores visibles junto a los precios:

- “Actualizado hoy”
- “Actualizado hace 3 horas”
- “Actualizado ayer”
- “Posiblemente desactualizado”

La información debe ser fácil de identificar sin saturar visualmente la pantalla.

6. MEJORAR UBICACIÓN Y DISTANCIA
En la ficha del establecimiento mostrar:
- Nombre
- Mercado o supermercado
- Distrito
- Dirección o referencia
- Distancia aproximada
- Botón “Ver ubicación”

Debe permitir que el comprador considere precio y cercanía al mismo tiempo.

7. CREAR ACTUALIZACIÓN RÁPIDA DE PRECIOS PARA VENDEDORES
Mejora el panel del vendedor para evitar que tenga que ingresar producto por producto cada vez que cambien los precios.

Crear una pantalla llamada:
“Actualizar precios”

Mostrar varios productos en una misma lista, por ejemplo:

Tomate       S/ 3.50/kg     [−] [+]
Limón        S/ 4.00/kg     [−] [+]
Papa         S/ 2.80/kg     [−] [+]
Cebolla      S/ 3.20/kg     [−] [+]

Permitir editar directamente el precio y finalizar con:
“Guardar cambios”.

Después de guardar, mostrar:
“Precios actualizados correctamente”.

8. ACLARAR QUÉ HACE CASERIA
En las primeras pantallas explicar brevemente la propuesta.

Para compradores:
“Organiza tu presupuesto, crea tu canasta y compara dónde te conviene comprar.”

Para vendedores:
“Muestra tu establecimiento, productos y precios para llegar a nuevos compradores.”

Debe quedar claro que CaserIA ayuda a comparar, organizar y conectar compradores con establecimientos.

CONTACTO / RESERVA:
Mantén una opción básica de contacto con vendedores, por ejemplo:
“Reservar por WhatsApp” o “Contactar por WhatsApp”.

Esta función debe servir para que comprador y vendedor coordinen disponibilidad y recojo. No diseñes todavía un sistema complejo de pago, delivery o seguimiento interno.

PREMIUM:
Mantén una sección Premium diferenciada.

Para compradores, puede mostrar como funciones futuras:
- Asistente nutricional con IA
- Escáner de alimentos con IA
- Canastas personalizadas
- Alertas de precios y promociones
- Historial de precios
- Historial y análisis de gastos
- Recomendaciones para aprovechar mejor el presupuesto

Para vendedores:
- Mayor visibilidad
- Promoción de productos y ofertas
- Información sobre productos más buscados
- Información sobre demanda local
- Herramientas avanzadas de gestión

No hagas que las funciones esenciales del MVP sean Premium.

NO IMPLEMENTAR TODAVÍA COMO FUNCIONES PRINCIPALES:
- Delivery propio
- Pago integrado
- Sistema completo de pedidos
- Seguimiento de entregas
- Funciones complejas de logística

Estas funcionalidades pertenecen al backlog y pueden mostrarse únicamente como futuras mejoras si fuera necesario.

RESULTADO ESPERADO:
Quiero una tercera versión mejorada del prototipo existente de CaserIA, conservando su identidad visual y flujo principal, pero haciendo la experiencia más clara, sencilla e intuitiva.

Las 8 mejoras deben quedar visualmente identificables en las pantallas para poder demostrar en un trabajo académico que fueron implementadas después del testeo con usuarios.

No rediseñes CaserIA desde cero. Mejora el prototipo actual.
